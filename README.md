# Avocado Signal

Build 1 of the Avocado Signal website.

## Stack

- Astro
- Static output
- Plain CSS
- No client-side JavaScript required for the homepage

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The site is intentionally static-first and lightweight so it can be deployed to a low-carbon static hosting provider with minimal overhead.
